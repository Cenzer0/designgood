# designgood review checklist

## Direction

- [ ] Is the visual thesis explicit?
- [ ] Does the signature element serve the user task?
- [ ] Does the interface avoid default template residue?

## Product clarity

- [ ] Can users identify where they are, what matters, and what to do next?
- [ ] Are labels, empty states, errors, and success messages domain-specific?

## States

- [ ] Loading
- [ ] Empty
- [ ] Error and recovery
- [ ] Success
- [ ] Disabled
- [ ] Keyboard focus
- [ ] Async status and duplicate-submit prevention

## Responsive and accessibility

- [ ] Narrow phone
- [ ] Tablet
- [ ] Desktop
- [ ] Keyboard-only path
- [ ] Focus visibility
- [ ] Contrast and non-color status
- [ ] Reduced motion
- [ ] Long content and overflow

## Score

Rate each from 0–2: specificity, hierarchy, signature, content, interaction, responsive, accessible, maintainable. Release at 13/16 or higher, with no blocking accessibility or destructive-action issues.
